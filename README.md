# WiFi Manager

轻量级 Windows WiFi 连接管理工具，支持自动重连、开机自启、系统托盘。

## 功能

- **WiFi 扫描** — 一键扫描周围网络，显示信号强度和加密方式
- **密码记忆** — 连接过的 WiFi 密码自动保存，断开再连无需重复输入
- **自动重连** — 断线后自动重连，指数退避策略（5s → 10s → 30s → 60s），配置重启后保持
- **开机自启** — 开机自动启动并最小化到系统托盘，不弹窗
- **系统托盘** — 关闭窗口时驻留托盘，双击恢复，右键退出

## 环境要求

- Windows 10/11
- Python 3.8+
- 依赖：`pystray`、`pillow`

## 安装

```bash
pip install pystray pillow
```

## 使用

```bash
python wifi_manager.py
```

1. 点击 **扫描WiFi** 刷新网络列表
2. 双击或选中网络后点击 **连接**，输入密码
3. 连接成功后自动开启重连监控
4. 勾选 **开机自启动** 实现开机自动连接
5. 点击关闭按钮会最小化到托盘，不会退出程序

## 配置文件

程序同目录下的 `wifi_config.json` 保存了密码和自动重连配置，删除可重置所有设置。
